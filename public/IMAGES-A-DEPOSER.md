# Images à déposer (export depuis Banani)

Le code est déjà prêt : dès qu'un fichier ci-dessous existe avec **le nom exact**,
l'image apparaît automatiquement. Tant qu'il manque, un placeholder propre s'affiche
(aucune image cassée).

## Comment exporter depuis Banani
Dans Banani, ouvre l'écran, puis pour chaque image : **clic droit sur l'image →
Enregistrer l'image sous…** (ou utilise l'export du design). Renomme et place les
fichiers exactement comme indiqué ci-dessous.

## Fichiers attendus (garde l'extension .jpg)

| Fichier à créer | Contenu (image Banani correspondante) |
|---|---|
| `public/hero.jpg` | Grande photo du hero (villa moderne, vue d'ensemble) |
| `public/properties/villa-moderne-4-chambres-kaporo.jpg` | Villa moderne 4 chambres |
| `public/properties/appartement-meuble-3-pieces-kaloum.jpg` | Appartement meublé (intérieur salon) |
| `public/properties/terrain-viabilise-800m2-nongo.jpg` | Terrain / parcelle |
| `public/properties/villa-familiale-5-chambres-ratoma.jpg` | *(pas dans Banani — photo au choix)* |
| `public/properties/bureau-amenage-kipe.jpg` | *(pas dans Banani — photo au choix)* |

## Notes
- Banani ne fournit que **3 images de biens** (villa Kaporo, appartement, terrain) +
  le hero. Les 2 derniers biens sont des exemples ajoutés : mets tes propres photos
  ou laisse le placeholder.
- Si tes fichiers sont en `.png` ou `.webp` au lieu de `.jpg`, dis-le moi et j'ajuste
  les chemins (ou renomme-les en `.jpg`).
- Formats conseillés : JPEG/WebP compressés (~1600 px de large max) pour rester
  rapides sur mobile.
